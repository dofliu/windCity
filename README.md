# 風場大亨 windCity

2.5D 等角視角的回合制風場經營遊戲，手機與電腦瀏覽器都能玩。玩家在自己的土地上取得資源、規劃風機與變電站，應對颱風、限電、陳情等事件，追求發電量、可用率與民眾支持度。每回合一季（3 個月）。

## 執行

不需要建置，直接用瀏覽器開啟 `index.html` 即可（本機檔案或 GitHub Pages 都可以）。

```bash
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000/>。

產生單一 HTML 檔（離線分享、或發布到 claude.ai Artifact）：

```bash
python3 tools/build.py              # dist/windcity.html
python3 tools/build.py --artifact   # dist/artifact.html
```

## 關卡

| 關卡 | 主題 | 新概念 | 回合 | 目標 |
|---|---|---|---|---|
| 測試關卡 | 自由建造 | 資金無限、可切換地圖、觸發事件、一鍵填滿風機 | 不限 | 不計成績 |
| 1 海岸初探 | 基礎 | 變電站併網、尾流排列、工班與備品 | 32 季 | 120 MW、300 GWh、可用率 96%、支持度 50% |
| 2 丘陵風場 | 地形與道路 | 稜線風、6.2 MW 機組需緊鄰道路、村落與回饋方案 | 32 季 | 110 MW、250 GWh、96%、55% |
| 3 颱風與電網 | 韌性 | 颱風機率 ×1.8、限電 25%、儲能、低費率 | 32 季 | 140 MW、330 GWh、95%、50%、儲能 3 座 |
| 4 老舊風場接手 | 維護與汰換 | 老化機組、故障、預算緊、汰舊換新 | 16 季 | 可用率 97%、60 GWh、55%、現金 100M |
| 5 離岸示範 | 海上施工 | 港口、工作船、海況窗口 | 24 季 | 離岸 100 MW、260 GWh、93%、50% |
| 6 大型離岸風場 | 規模化 | 海上變電站與海纜、浮動式 15 MW、深海 | 32 季 | 離岸 300 MW、850 GWh、92%、50% |

評等：全部目標達成且期末現金為正 S；全部達成 A；達成 3/4 以上 B；一半以上 C。拿到 C 以上（至少一顆星）算過關。

關卡設定都在 `js/levels.js` 的 `LEVELS`：地圖生成器與參數、起始土地與資源、回合數、目標、可用機型與設施、難度旋鈕（`mod`）。新增一關只要加一筆設定。

## 畫面與聲音

- **地圖美術**：大尺度色塊讓草地自然不呆板、每格受光漸層與崖頂亮邊、懸垂草皮與帶石塊樹根的土層；海水依離岸距離由淺綠漸深；四季農田（冬油菜花、春水田秧苗、夏綠稻、秋收稻草捆）；沙灘濕沙帶與貝殼、路口斑馬線。
- **樹木與建築**：杉木、闊葉樹、木麻黃、檳榔樹、竹叢，冬季櫻花、秋季紅葉，樹隨風搖擺；三合院、屋頂太陽能板的透天厝、門口機車，每個村落中心有一座廟（燕尾脊、燈籠、香爐冒煙）。
- **動態細節**：轉動的葉片影子、天上的雲、水田白鷺鷥（有的站在水牛背上）、春夏蝴蝶、順風移動的浪紋與強風白浪、測風塔風向袋、維運中心旗幟。
- **日夜循環**：約 2.5 分鐘一輪，黃昏暖色調、夜晚星空；民宅窗戶、路燈、風機航空警示燈、港口與變電站會亮燈。
- **生活感**：道路上有車流、海上有漁船、離岸關卡有工作船往返港口與工地、鳥群飛過。
- **回饋特效**：建造揚塵、拆除煙塵、完工閃光、換季橫幅、資金數字滾動與增減閃色。
- **背景音樂**：Web Audio 即時合成，隨季節換情緒（冬季東北季風、春雨、夏日、秋天），颱風時轉為緊張版本，關卡選單是平靜主題。
- **環境音**：風聲隨本季風速與陣風變化、海浪、颱風雨聲。
- **音效**：按鈕、建造、完工、拆除、購買、研發、事件、颱風警報、過關與失敗。
- **設定**（選單 → 設定，或頂列的聲音按鈕）：音樂、音效、環境音音量、全部靜音、日夜循環開關，存在瀏覽器。瀏覽器規定要先點一下畫面才會開始出聲。

## 管理介面：設定開放哪些關卡

每一關可以設為「開放」「過關後開放」（上一關至少一顆星才解鎖）或「關閉」。

- **發布在 claude.ai 上**：設定存在頁面的共用資料庫（`config/levels`），所有開啟頁面的人立即套用；只有擁有者或編輯者看得到「管理介面」按鈕、能修改。
- **本機檔案或 GitHub Pages**：網址加上 `#admin` 才會出現管理按鈕，設定只存在這個瀏覽器（沒有伺服器可以共用）。

## 測試與平衡工具

需要 Node.js 與 Playwright。

```bash
node tools/smoke.js                       # 開啟頁面，確認沒有錯誤
node tools/levels-smoke.js 3              # 每一關推進 3 季並截圖到 tools/out/
node tools/ui-check.js                    # 測試工具與管理介面的功能檢查
node tools/fx-check.js                    # 日夜截圖、音訊是否真的有輸出
node tools/art-shots.js                   # 美術特寫截圖（村落、四季農田、丘陵、離岸）
node tools/balance.js all 4 good,naive    # 平衡測試：每關用好策略與草率策略各跑 4 個種子
```

`tools/bot.js` 是平衡測試用的機器人：`good` 照教學做好每件事（先蓋變電站、垂直風向排列、積極維護、備品葉片、道路、維運中心、回饋方案、保留工作船給維修），`naive` 只顧蓋風機。調整關卡數值後跑一次 `balance.js`，確認好策略多半能拿到 S、草率策略過不了關。

遊戲邏輯的隨機數可以用 `window.__grand` 指定種子重播，畫面特效使用另一個獨立的隨機數。

## 簡化與遊戲化說明

- 造價與售電費率經過遊戲化縮放，讓風機在幾季內回本；功率曲線、容量因數、尾流、可用率等技術面依實際行為建模。
- 颱風預防性停機屬於外部因素，會損失發電但不計入可用率（參考 IEC 61400-26 的可用率定義）。
